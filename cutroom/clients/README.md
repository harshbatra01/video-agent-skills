# Client files

One file per real project, written so Claude can pick any of them up cold. Snapshot of 14 Oct 2026.

## Index
- `immufix.md`: Immufix, 8 paid-social ads (Meta, TikTok) built around an athlete presenter; finished through v10;
  archive licences, music plan and compliance questions block paid use.
- `vc-music-pages.md`: two rap news pages (@zonegbp, @beatswitchfm) built daily by a news pipeline (1 video + 1
  carousel per page per day).
- `outcome.md`: Outcome (outcome.xyz, a crypto prediction market), faceless automated posts; sample pack v2 in the house
  look awaits a keep-or-cut verdict.
- `cracked-sports-edits.md`: beat-synced "cracked" sports edits for music promo pages; pilot v8 and three wave-1 edits
  await review.

## How to use these files
- **Read "Start here" first.** It gives the status and the very next step.
- **Every file has the same sections in the same order:** start here; what the client is and wants; formats and specs;
  the house look and taste rules (verdicts quoted in the client's or the team's own words); every deliverable and version
  with its status; the review history round by round; what went wrong and the fix; open items and next steps; where the
  files lived; which skills and pipelines to use, with the job's workflow step by step.
- **People:** "the user" is the editor; "the reviewer" signs off.
- **Quoted verdicts are rules for that client.** A rejection is about that placement unless it says "never".
- **Paths are on the original machine.** Projects, renders and media are not in this repo. Some pipelines named here
  (news desk, faceless studio, ad build kit) are not included; the edits kit is in `library/pipelines/edits-kit/`.
- **Private pages** are marked "(private page)": the links are not shared.
- **Accounts, keys, licences, fonts and logins** are never in the repo. Each file lists what has to be set up.
- **House rules for any of these jobs:** see `../CLAUDE.md`.
- **Risks to decide are marked "Decisions" or "Risks"** in the open items: licences, compliance, platform permissions,
  rights to borrowed footage. They are business calls, not editing calls.
