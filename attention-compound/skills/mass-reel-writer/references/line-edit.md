# Line editing: the professional passes

Run these in order on every draft. Each pass has one job.

1. **Promise pass.** Write the hook's promise in one line. Strike any line that doesn't pay it. Check the band, the
   hook, the last unit and the caption say the same thing.
2. **Reveal pass.** Underline every instruction ("set up", "go to", "you should"). Turn each into a fact about the
   world ("Google shows products in 8 places for free") unless it's the one closing action.
3. **Picture pass.** Every unit gets a name or object the viewer can see. Replace "your business", "your store", "AI"
   with a named thing where you can.
4. **Number pass.** One simple number per unit. Cut any second number in a sentence. No maths.
5. **Gap pass.** Find the biggest surprise and move it to "and last". The second-biggest goes first.
6. **Plain-words pass.** Any word a 14-year-old would ask about goes on screen, not in the voice.
7. **Friend-voice pass.** Read it as if teasing a friend, not teaching a class. Swap "you should" for "you think" or a
   plain fact. Drop "but actually".
8. **Breath pass.** Read aloud at speed. Join choppy fragments into one spoken chain with "and"; split anything you
   can't say in one breath.
9. **Keep pass.** Does it end on a list worth saving or a line worth quoting? If not, write that line.
10. **Truth pass.** Every claim against today's source. "Can" where the source says "may". No superlatives, no
    motives, no "I tried it" the person didn't do.
