# Script review

Run this before any script goes to the client. Score each line 0 (fails), 1 (partly) or 2 (passes) and write one
reason. Then run `python3 tools/script_check.py --md <file> --keyword <WORD>`, the DADDY gate and the
goal-alignment review. Claude can't watch or hear the final video; say so in the review.

## A. Callaway checks
| # | Check |
| --- | --- |
| C1 | The idea is a clear one-liner a wide audience would want (packaging) |
| C2 | The first line confirms what the video is about (click confirmation) |
| C3 | The hook passes all 4 commandments: alignment, speed to value, clarity, curiosity |
| C4 | The hook format fits the story structure (list hook for a listicle) |
| C5 | Every unit is new to most viewers (shock score 50+), not common knowledge |
| C6 | Units climb in value; the first unit is strong, never the weakest |
| C7 | Each unit has a plain what, an example and why it matters (value loop) |
| C8 | Bridges between units keep the next one feeling necessary (rehooks) |
| C9 | One target emotion, and the script delivers it |
| C10 | The CTA solves the problem the video showed (native embed), not an ad |
| C11 | The ending leaves a high note |
| C12 | As short as it can be |

## B. Rani and Cutroom checks
| # | Check |
| --- | --- |
| R1 | Widest rung that still fits the lane |
| R2 | Famous names the viewer already knows |
| R3 | A number in most units, every one checked |
| R4 | Biggest surprise last ("and last") |
| R5 | A turn line people could quote |
| R6 | Same keyword in the voice, end card and caption |
| R7 | 35-60 s, 100-170 words, no greeting, no em dashes |
| R8 | The house hook rules K1-K13 (`hooks.md`) |

## C. House voice (user verdict, 20 Oct 2026)
| # | Check |
| --- | --- |
