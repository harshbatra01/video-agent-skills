## How to use these files
- **Read "Start here" first.** It gives the status and the very next step. Anything newer than the snapshot date: ask
  Kanishk before acting.
- **Every file has the same sections in the same order:** Start here; what the client is and wants; formats and specs;
  the house look and taste rules (verdicts quoted in the client's or the team's own words); every deliverable and version
  with its status; the review history round by round; what went wrong and the fix; open items and next steps; where the
  files live on Kanishk's PC; which kit skills and pipelines to use, with the job's workflow step by step.
- **People:** Jaden is the boss (founder of Vision Clipping); Kanishk is the editor, called "the user" in the files.
- **Quoted verdicts are rules for that client.** A rejection is about that placement unless it says "never". New taste
  notes from you win: put them in `~/VisionKit/mine/overrides.md`.
- **Paths are on Kanishk's Windows PC.** Projects, renders and media are not in the kit: ask Kanishk for what you need.
  Copies of the code are in `~/VisionKit/kit/library/pipelines/`: the three pipelines (newsdesk for the music pages,
  outcome-studio, edits-kit) and the smaller tool sets (ad-build-kit for Immufix, review-pages, youtube-research). The
  kit copies were already patched for the Mac where the library README says so; each client file's last section has the
  Mac notes for its tools.
- **Private pages:** the claude.ai links in these files live in Kanishk's account. Ask him to share them.
- **"Needs his own":** accounts, keys, licences, fonts and logins are never in the kit. Each file lists what you need to
  set up yourself (for example an Epidemic plan that covers client work, font licences, throwaway monitoring logins).
- **House rules for any of these jobs:** never overwrite a delivered file (new `_v2`, `_v3`); disable, never delete;
  build edits as layers in Premiere and use After Effects only for elements; one heavy job (render, big download, long
  AE run) at a time; hold renders when the user is busy; check your own work with numbers before calling it done.
- **Risks to decide are marked "Decisions for Jaden" or "Risks"** in the open items: licences, compliance, platform
  permissions, rights to borrowed footage. They are business calls, not editing calls.
- **Send fixes back:** if a client file is wrong or out of date, note it in `~/VisionKit/mine/feedback-for-kanishk.md`;
  do not edit the kit's files.
