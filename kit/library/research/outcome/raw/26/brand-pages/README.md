# Provenance of these files
All files are from https://brand.outcome.xyz/ (Outcome's own public Brand Guide), read on 14 Oct 2026 with plain GET requests. No login, no portal access, no asset-pack download.

- DESIGN.md: byte-for-byte copy of https://brand.outcome.xyz/DESIGN.md (15,473 bytes, text/markdown).
- The other .md files: text rebuilt from each page's own embedded data (the pages are client-rendered). Wording is exact, headings and lists are rebuilt, layout is approximate. Navigation arrows at the end of some pages are page chrome.
- colors.md: the page text plus the palette hex table that sits in the same page data (11 palettes x 11 steps). The theme-to-step mapping is in DESIGN.md section 2.
- typography.md: carved from the brand-guide index page. The type scale there shows pixel sizes and line heights only as blanks (they are filled in by the page's scripts), so those numbers are NOT captured; DESIGN.md section 3 gives sizes in words.
- Not saved: /brand-guide/iconography (no text in the saved HTML), /brand-guide/typography as its own route (not fetched), and the gated Partnerships / KOLs pages (social templates, brand kit, lockups; they show nothing without portal access).
- Note the guide disagrees with itself on palette: design-language.md says four hues (green, fuchsia, turquoise, neutral), colors.md says nine palettes and eight themes, DESIGN.md says ten themes.
