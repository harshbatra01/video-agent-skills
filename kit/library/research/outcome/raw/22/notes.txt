How the numbers were read
- YouTube: public watch pages (views, likes, date, subscribers) via tools\yb.py (ids, tag, q, chan); Shorts search via tools\qs.py (Shorts filter, US locale, period filter). Hashtag pages /hashtag/<tag>/shorts with continuations (visitorData needed in the InnerTube call, fixed in yb.py).
- Stills: YouTube's own frame0 + hq1/hq2/hq3 previews (tools\strip.py). TikTok cover frames via tikwm (tools\ttcovers.py). No video was downloaded or watched.
- TikTok: tiktok.com is blocked from this PC (connection timeout). Routes that worked: tikwm single-video API (vt.py tt), r.jina.ai on tiktok.com/embed/@handle for creator accounts (tools\ttembed.py; verified brand accounts return nothing), r.jina.ai html on profiles for follower counts. tikwm user/search endpoints are behind Cloudflare (403). TikTok discover pages via jina return no video list.
- X: syndication timeline (latest ~20 posts only) via r.jina.ai (direct calls hit HTTP 429), parsed with tools\x_tl.py.
- Web search: weak for short video; used only to find TikTok URLs.
